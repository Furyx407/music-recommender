# Requirements:
Python,
Yt-DLP,
Beautiful Soup 4,
Requests,
Lingua,
Re,
Urllib

# Installation
Download and execute the .exe from releases

**OR**

Clone the Github repo with:
``` 
git clone https://github.com/Furyx407/music-recommender
```
Then install dependencies with: 
```
pip install -r requirements.txt
```
Execute the python file using:
```
python Main.py
```
or
```
python3 Main.py
```
